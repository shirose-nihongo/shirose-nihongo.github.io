# Struktur ujian 機械金属加工 1号 (dari contoh soal resmi JAIM, DOC-003)

Dirangkum dengan kata sendiri; isi soal tidak disalin. Belum tentu identik dengan ujian sebenarnya.

- Total 40 soal, 80 menit, berbasis komputer (CBT).
- 学科 (soal 1–30): pilihan dua (A benar / B salah). Lulus bila minimal 65% (20 dari 30).
- 実技 (soal 31–40): empat pilihan A–D. Lulus bila minimal 60% (6 dari 10).
- Ada soal bergambar (tanda JIS, histogram, simbol las, label PL, alat ukur, simbol toleransi geometris).
- Topik 学科: kebakaran minyak, tanda JIS, prinsip mutu, histogram, 4S, pH, komposisi air, kewajiban hukum keselamatan, pembumian, pemeriksaan sebelum kerja, heat stroke, sarung tangan dan mesin berputar, standar kerja, pemeriksaan sampel, diagram pencar, perawatan mesin, kondisi pemotongan dan kekasaran, urutan pengecatan, akurasi pengeboran, modulus elastisitas, arti kode baja, interval kalibrasi, metode pemeriksaan, jangka sorong, kesalahan ukur, simbol chamfer, simbol las.
- Topik 実技: pakaian kerja untuk percikan api, label PL, data hitung vs ukur, pemeriksaan akhir, penanganan pemeriksaan terlewat, mikrometer, depth gauge, dial gauge, nama simbol toleransi geometris, istilah CAD.
- Dokumen resmi lain (DOC-004) menyebut 2号 機械金属加工 hanya 実技 dengan standar setara 技能検定1級; materi 2号 BELUM dikerjakan.
